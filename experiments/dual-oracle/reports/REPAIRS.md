# 试运行修复日志

## 第 1 轮

dff8r 的定向 TB 输出使用了分类别名及附加标签。旧解析器要求标签精确等于预设枚举，导致可用的场景因格式被拒绝。现在对公开标签做确定性的同义映射，保留原始响应，继续校验 spec 原文引用、端口、整数范围和周期上限。离线复验时用归档的第二份响应恢复了场景，输入与期望值仅来自该 API 响应。Python 解析也保留了在 reference 函数前定义的可执行辅助函数。

edgecapture 和 fsm3s 的响应在同一轮复核时也出现了标签别名。复位与释放改为验证场景中的实际驱动顺序，边界覆盖改为验证实际输入端点，保留可核对的 spec 引文。原始响应、旧状态、恢复后的状态分别保存。

## 第 2 轮

CVDP-ECov 的九道 copilot 开发题没有独立的 spec 文件，公开行为说明在发布记录的 instruction 字段。读取器现在优先读取 spec 文件，并在该字段为空时读取公开 instruction 的叙述，剥离代码围栏和模块块。空说明会在发请求前报错。首次两道 B 题的空说明请求被中止，现有收据全部归档。该轮没有可用产物进入评分或选 N。A 组有效断点继续使用。

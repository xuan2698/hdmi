# Stimulus-v2 CVDP 形式化对象溯源

结论适用于 `pilot` 的 `cfa9b5905b3961840f57b9c5dca04d06e8d36311`。十道 CVDP 开发题均有一份发布参考 RTL，均有 **0 份独立 proxy**。未曾调用任何模型生成 v2 的 CVDP proxy。v2 的 API 模型 `deepseek-v4.1-flash` 生成的是输入激励 Python 代码。[生成入口](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v2/base.py) · [v2 协议](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v2/protocol.json)

`stimulus-v1/common.py` 从锁定的 CVDP-ECov 发布数据选取十个开发题，按归档顺序用两个换行连接 `rtl_files[*].content`，放入 `row["gold"]`。`stimulus-v2/run.py` 复用 v1 的 `stimulus-v1/guidance/<题号>/catalog.json`，每题 24 个 G。G 用固定规则直接变异同题的 `row["gold"]`。O 在参考 RTL 与对应 G 上做仿真诊断，O+F 同时把这对设计送给形式化脚本。求解时模块重命名、RAM 八地址搜索和兼容转换由脚本完成。没有单独的 API 代理文件可以复用。[数据装载](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v1/common.py) · [G 规则与变异基准](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v1/guide.py) · [逐题 G 清单](https://github.com/xuan2698/hdmi/tree/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v1/guidance) · [v2 生成端](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v2/run.py) · [v2 求解入口](https://github.com/xuan2698/hdmi/blob/cfa9b5905b3961840f57b9c5dca04d06e8d36311/stimulus-v2/solver.py)

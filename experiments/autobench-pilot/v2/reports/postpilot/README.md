# 第二次试运行复盘

在已保存的 60 次二次试跑上重算。脚本仅读取已有 RTL、激励、期望输出和模型产物，并使用 Icarus 与现有的隔离 Python 执行器复放。评测证据保存在本目录，生成流程未读取本目录。

## 检出和漏检

- [新旧检出口径](detection.csv)保留每种配置的 94 个 H 评测机会。旧口径要求同周期、同输出出现 golden 没有的错误。新口径要求最终 TB 先通过 golden，失败的 TB 的 H 检出计零。各配置同时列出 golden 误报率。
- [全配置均未暴露的 H](never_exposed_H.csv)按题和变异体编号列出四个变异体。每个均使用当时十份最终激励，[探针记录](never_exposed_H_probes.json)同时列出评分采样和原始四态差异。这里的“未传播”以原试运行评分域为准。2014_q3c 的两处原始差异发生在 golden 未定义的输出上，ece241_2014_q5a 的原始差异发生在评分边沿前。
- [已暴露但无新增报错](exposed_H_misses.csv)按一次 TB 对一个变异体计数。逐差异位置分类后，混合个案按“共有错误、期望与变异体一致、未检查”的优先级归入一个原因。[差异位置](exposed_H_difference_sites.json)保留所有位置。[例子](miss_examples.json)中共有错误只有一组 TB 与变异体，列出同组的两个周期。

## 代理与探针核对

- [反馈去重](feedback_issue_points.csv)复放 B-O、O-O 的每一轮，使用该轮实际检查器和可见的 G 变异体。回放逐轮核对原始计数，覆盖日志中因示例上限而未列明的记录。分组键是题目、输出信号和对应公共 spec 条款。edgecapture 按代理差异位是否包含本拍下降沿划分捕获和保持。review2015_fsmseq 的检测和保持在公共文本中共用一个条款。
- [代理正确性与 R2/R3 分歧率](proxy_correctness_disagreement.csv)用官方 golden TB 验证六题代理。R1_enum_compatible 单列使用与试运行一致的枚举兼容转换后的结果。分歧率采用每题十份最终激励的“周期 × 输出信号”样本，以双方均为已知值的样本作为主分母，同时报告含 X/Z 的四态口径。
- [G 标签精确复核](G_label_audit.json)覆盖档案中全部两条“未到达 / 未感染”候选观测，均来自 #75 的 G1-34。探针直接插在复位分支的赋值前，以目标寄存器的三位宽度记录两种右值。样本不足以估计全体诊断的准确率。

## 结果

B-O 在新口径下以 48/94 居首。全批 100 个已暴露但无新增报错的评测机会中，90 个来自 circuit10 的九份全输出为 None 的检查器，它们的 golden 通过没有实际检查。分开看其余五题，通过 golden 的 TB 中，漏检来自激励或原评分域的曝光限制。判断瓶颈时应同时看[逐题拆分](bottleneck_by_task.csv)、golden 误报和原始四态波形证据。

复跑使用 `python3 postpilot_analysis.py`，并将 Icarus Verilog 与 bwrap 放在 PATH 中。

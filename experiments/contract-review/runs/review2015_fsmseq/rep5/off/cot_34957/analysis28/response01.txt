The ports are all one bit wide: `reset`, `data`, and `start_shifting`. There are no multi-bit boundary values to interpret, so the checker should treat every signal as a Boolean sampled at the active clock edge. The only meaningful numeric boundaries are 0 and 1, and the only state boundary that matters is the transition into the sticky found condition.

The machine has five conceptual states: no-prefix, prefix `1`, prefix `11`, prefix `110`, and found. The output `start_shifting` is 0 in all prefix states and 1 in found. Because the output is sticky, the checker should compare the expected output after each sampled edge against the post-edge state, not against the pre-edge state alone.

The most useful checker point is same-edge completion. When the pre-edge state is prefix `110` and the sampled row has `reset=0, data=1`, the expected post-edge output is already 1. The checker must not require the flag only on the following row. Equally important, reset wins on the sampled row: if `reset=1`, expected `start_shifting=0` after that edge even when the data bit would otherwise complete the pattern or when the machine was already found. After such a reset row, the machine returns to no-prefix, so a later non-reset row must not inherit the old found status.

Once found, the output is sticky until reset. A later `data=0` row must still show 1; a later `data=1` row must also show 1. Only a sampled reset row may clear it. Mid-row changes are irrelevant to the row just sampled: if `data` or `reset` changes after the posedge but before the next edge, that new value belongs to the next row’s expectation and must not retroactively change the current row.

Worked alignment: suppose the sampled history has established prefix `110`. Current row `reset=0, data=1` must yield `start_shifting=1` immediately. Next row `reset=0, data=0` must still yield 1. If instead the next row is `reset=1, data=1`, the synchronous reset wins and the expected output after that edge is 0. A following row `reset=0, data=1` must still expect 0, because only the first bit of a new sequence has been seen.

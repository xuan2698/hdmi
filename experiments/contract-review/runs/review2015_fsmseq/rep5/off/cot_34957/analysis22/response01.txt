The public interface is narrow: one-bit synchronous active-high `reset`, one-bit `data`, one-bit registered `start_shifting`, and a single `clk`. There are no multi-bit buses, so no width truncation or sign-extension concerns arise. The only boundary values are 0 and 1 on each port. The checker should treat `reset` and `data` as sampled at the posedge; mid-row changes are legal but belong to the next sampled row. Because `start_shifting` is registered, its value on a row reflects the state entered by that row's sampled edge, not combinational decoding of the current `data`.

The useful checker focus is the distinction between the completing edge and the following edge. On the row whose sampled `data` completes `1101`, the post-edge output must already be 1. On the next non-reset row, it must remain 1 regardless of `data`. A sampled `reset=1` must force the post-edge output to 0 even if `data=1`; the following non-reset row must then reflect only the new prefix history, not the old sticky flag.

A compact trace: assume the machine has already seen `110` and the checker drives `reset=0, data=1`. After the posedge settles, `start_shifting` must be 1. Next row, drive `reset=0, data=0`; output must stay 1. Next row, drive `reset=1, data=1`; output must become 0 after the edge. Next row, drive `reset=0, data=1`; output must remain 0, since only the first bit of a fresh `1101` has been sampled. This single trace checks registered assertion, sticky hold, synchronous clear, and reset priority.

The checker should avoid assuming any particular internal encoding or that the machine stops tracking prefixes after acceptance. Only the observable rule matters: once the completing edge is sampled, `start_shifting` is 1 on every subsequent sampled row until a sampled reset makes it 0. Mid-row changes to `reset` or `data` must not retroactively alter the just-sampled row; they are inputs to the next sampled edge. Since all ports are one bit, the checker can compare exact 0/1 values and needs no masking. The main risk is off-by-one-row timing: the flag is set on the completing row, not one row later, and cleared on the reset row, not one row later.

Reset is active-high synchronous: only a high `reset` sampled at a rising edge forces `start_shifting` to 0 and returns the machine to its initial state. Power-up behavior is not specified by the public interface, so the checker should not assume any particular pre-reset state; it should apply a reset edge before judging normal operation. Because inputs are sampled at the posedge, mid-cycle changes must not influence the expected result for that edge. A useful checker point is the `110`-then-`0` fallback: after seeing `110`, a `0` must return to the trailing-`0` state, not the trailing-`1` state. For example, input `01101` must assert `start_shifting` on the final `1`; a wrong fallback leaves the machine in the `11` prefix and misses acceptance.

The machine has five meaningful states: an initial state S0, three partial-match states S1, S2, S3, and a terminal match state S4. In S0 the machine has seen no useful prefix of 1101. In S1 it has seen a trailing 1. In S2 it has seen a trailing 11. In S3 it has seen a trailing 110. In S4 it has seen the full 1101 and asserts start_shifting forever until reset.

Transitions on data are as follows. From S0, data=0 stays in S0; data=1 goes to S1. From S1, data=0 goes to S0; data=1 goes to S2. From S2, data=0 goes to S3; data=1 stays in S2, because the trailing 11 is still a valid prefix. From S3, data=0 goes to S0; data=1 goes to S4, completing 1101. From S4, any data value stays in S4. This is the absorbing property: once the sequence is found, no later data bit can clear start_shifting. Only a sampled reset=1 returns the machine to S0 and deasserts start_shifting.

The output start_shifting is 0 in S0 through S3 and 1 in S4. It is a sticky match flag, not a sliding-window detector output. The checker must not recompute it from the most recent four bits; for example, after a match, a later 0 bit does not clear it even though the last four bits are no longer 1101.

Reset is active high and synchronous. On a sampled rising edge with reset=1, the machine goes to S0 and start_shifting becomes 0 after the edge settles, regardless of data. Power-up output is unspecified until the first sampled reset. The checker should ignore start_shifting before any sampled reset, then compare the settled output after each edge.

A short worked example: suppose the machine powers up with unknown start_shifting. A sampled edge with reset=1 and data=0 must settle to S0 with start_shifting=0. Then data bits 1,1,0,1 across successive sampled edges move S0→S1→S2→S3→S4, and start_shifting becomes 1 after the fourth edge. A mid-cycle data change after that edge does not undo the match. Subsequent data bits leave the machine in S4 with start_shifting=1 until another sampled reset=1 clears it.

For the final Python checker, the useful focus is to model each row in three phases: pre-edge sampled inputs, post-edge settled state and output, and optional mid-cycle changes that become the next row’s starting inputs. Reset applies only in the sampled-edge phase. Before any sampled reset, start_shifting is unspecified. After a sampled reset, the checker compares the settled output after each edge, enforces the absorbing rule for data in S4, and requires a sampled reset to clear S4. It must not let a post-sample data change affect the transition just sampled, and it must not infer start_shifting from the last four input bits. These rules align the checker with the public specification’s synchronous reset, sampled-edge semantics, and truly sticky match behavior.

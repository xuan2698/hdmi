The machine needs five conceptual states: no useful prefix, prefix `1`, prefix `11`, prefix `110`, and found. In the ordinary states, transitions follow the longest suffix of the received stream that is also a prefix of `1101`. From no-prefix, `data=1` advances to prefix `1`, while `data=0` stays. From prefix `1`, another `1` advances to prefix `11`; a `0` returns to no-prefix because `10` has no useful suffix. From prefix `11`, `data=0` advances to prefix `110`; `data=1` keeps prefix `11`, since the trailing `11` is still a valid prefix. From prefix `110`, `data=1` enters found; `data=0` returns to no-prefix, since `1100` has no useful suffix. The found state is absorbing for data: every later bit leaves it in found and keeps `start_shifting=1`.

Output behavior is registered. `start_shifting` is 0 in all ordinary states and becomes 1 only after the sampled edge that completes `1101`. It remains 1 in found until a sampled synchronous reset. Reset has priority at the sampled edge: if `reset=1` is sampled, the next state is no-prefix and the registered output is 0, regardless of `data`. Mid-cycle input changes after sampling do not alter the current row’s expected post-edge output; they only affect the next sampled edge.

A useful checker focus is the detection row itself. Suppose the machine is in prefix `110` before a sampled posedge, with `reset=0` and `data=1`. Before the edge, `start_shifting` is 0. After the edge settles, the registered output must be 1. The checker should compare the post-edge registered value, not the pre-edge value or a purely combinational “sequence complete” signal. A combinational interpretation would expect 1 on the detection row but may then expect the following row differently, causing a one-cycle lag mismatch and falsely rejecting a correct registered design.

Thus the final Python checker should sample only settled post-edge outputs, apply synchronous reset priority at that edge, ignore mid-cycle changes for the current row, and treat found as absorbing until a sampled reset. All signals are one bit, so only binary combinations matter.

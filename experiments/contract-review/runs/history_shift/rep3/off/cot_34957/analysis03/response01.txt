The register is a single 32-bit global branch history state. Its value is exposed directly as `predict_history`, so the output is simply the current state; there is no separate combinational output path or additional state. The only state transition mechanisms are the asynchronous reset and the rising-edge next-state function.

The asynchronous reset is a positive-edge-triggered override on `areset`. Whenever `areset` is high, the history register is forced to zero immediately, independent of the clock and independent of all other inputs. This means a mid-row assertion of `areset` must be reflected in the sampled output before the next rising edge, and any pending prediction or misprediction inputs are ignored while reset is asserted. When `areset` is later deasserted, that deassertion is carried forward, and the next rising edge resumes normal next-state evaluation from zero.

For the normal non-reset next-state function, the checker should evaluate one next-state expression at each settled rising edge. If `train_mispredicted` is high at that edge, the register loads `{train_history[30:0], train_taken}`, and this takes priority over any simultaneous prediction. If `train_mispredicted` is low and `predict_valid` is high, the register shifts in `predict_taken` from the LSB side, producing `{predict_history[30:0], predict_taken}`. If neither is high, the register holds its value. The misprediction priority exists because the pipeline flush removes the branch currently making a prediction, so the prediction must not be allowed to corrupt the restored history.

A short worked example illustrates the priority and the reset interaction. Suppose the current history is zero. A row drives `predict_valid=1`, `predict_taken=1`, `train_mispredicted=0`. After the rising edge settles, `predict_history` becomes `32'h0000_0001`. If the next row drives `train_mispredicted=1`, `train_taken=0`, `train_history=32'h0000_0001`, and also `predict_valid=1`, `predict_taken=1`, the misprediction wins: the register becomes `{32'h0000_0001[30:0], 1'b0} = 32'h0000_0002`, not the prediction result. If `areset` were asserted mid-row instead, the register would immediately become zero regardless of these inputs, and the next sampled edge would start from zero.

The key point for the final Python checker is to separate the asynchronous reset override from the edge-sampled next-state logic. Reset should be applied immediately whenever asserted, including on mid-input changes, while all other inputs should only affect the next settled rising edge. Within that edge-sampled logic, misprediction must be checked before prediction, and prediction before hold. This ordering, plus the immediate reset override, captures the public specification without requiring any additional state beyond the 32-bit history register itself.

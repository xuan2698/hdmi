The public spec describes a 32-bit global branch history shift register with three edge-sampled behaviors and one asynchronous override. The checker should model a single 32-bit state register, `predict_history`, and evaluate it at each settled rising edge according to a strict priority: asynchronous reset first (immediate, not edge-sampled), then `train_mispredicted`, then `predict_valid`, then hold. The reset is positive-edge-triggered asynchronous, so whenever `areset` is high the register is zero regardless of clock phase; when `areset` deasserts, the next rising edge resumes normal evaluation from zero.

The most useful distinguishing point for the final Python checker is the interaction between the asynchronous reset and the edge-sampled priority logic, plus the misprediction-over-prediction priority. A naive checker might treat all inputs uniformly at the rising edge, or might let a simultaneous prediction overwrite the restored history. The spec explicitly says misprediction wins because the pipeline flush also flushes the branch currently predicting. So at a settled rising edge with `train_mispredicted=1`, the next state is `{train_history[30:0], train_taken}` regardless of `predict_valid` and `predict_taken`. Only when `train_mispredicted=0` and `predict_valid=1` does the register shift in `predict_taken` as `{predict_history[30:0], predict_taken}`. Otherwise it holds.

A short worked example: start with history zero. Row A drives `predict_valid=1, predict_taken=1, train_mispredicted=0`; after the rising edge settles, history is `32'h0000_0001`. Row B drives `train_mispredicted=1, train_taken=0, train_history=32'h0000_0001`, and also `predict_valid=1, predict_taken=1`. The misprediction wins, so the register becomes `{32'h0000_0001[30:0], 1'b0} = 32'h0000_0002`, not the prediction result. If `areset` is asserted mid-row instead, the register immediately becomes zero, and the next sampled edge starts from zero.

The checker should therefore separate two mechanisms: an immediate reset override applied whenever `areset` is high (including mid-input changes after sampling and before the next edge), and an edge-sampled next-state function that checks `train_mispredicted` before `predict_valid` before hold. No additional state beyond the 32-bit register is needed. The final Python checker should sample after the posedge has settled, carry mid-row input changes to the next row's start, and ensure that a prediction coincident with a misprediction never corrupts the restored history.

The design is a single 32-bit global branch-history register with three control paths and an asynchronous reset. All data inputs are one bit except `train_history`, which is 32 bits; the sole output `predict_history` is 32 bits and reflects the register value after the sampled clock edge has settled. Because the register is exactly 32 bits wide, every shift discards the oldest bit at position 31 and every insertion places the newest outcome at bit 0. There is no counter, no valid bit, and no auxiliary state: the entire architectural state is the 32-bit history word.

Boundary values follow directly from that width. The all-zero word is the reset value and also the state after 32 consecutive zero outcomes. The all-ones word `32'hFFFF_FFFF` is reachable and is the natural saturation case for shift tests. A single one at the LSB (`32'h0000_0001`) represents the most recent branch taken with all older history zero; a single one at the MSB (`32'h8000_0000`) represents the oldest recorded branch taken, and the next shift drops it. These four words—zero, one, all-ones, and MSB-only—are the highest-value boundary vectors for the final checker, since they exercise insertion at bit 0, discard at bit 31, and the wrap between them.

The priority ordering is the central semantic point. `areset` is asynchronous and positive-edge triggered, so it overrides everything and forces the register to zero independently of the clock. Among the synchronous controls, `train_mispredicted` has highest priority: when asserted, the next state is `{train_history[30:0], train_taken}`, i.e. the pre-branch history shifted left by one with the actual outcome inserted at the LSB, and `train_history[31]` is discarded. Next is `predict_valid`, which yields `{predict_history[30:0], predict_taken}`. If neither is asserted, the register holds. The coincident case `train_mispredicted = 1` and `predict_valid = 1` must resolve to the misprediction update, because the pipeline flush also removes the branch currently predicting; a checker that lets the prediction shift win, or that applies both, will fail exactly there.

A short worked example clarifies the ordering. Starting from zero, a prediction with `predict_taken = 1` gives `32'h0000_0001`. On a later row with `train_mispredicted = 1`, `train_taken = 0`, `train_history = 32'h0000_0001`, and simultaneously `predict_valid = 1`, `predict_taken = 1`, the result is `{32'h0000_0001[30:0], 1'b0} = 32'h0000_0002`; the prediction is suppressed. If `areset` is asserted mid-row instead, the register clears immediately and the next sampled edge begins from zero.

For the final Python checker, the useful focus is to encode the register as one 32-bit state updated by the strict priority chain reset, then `train_mispredicted`, then `predict_valid`, then hold, and to include an explicit coincident prediction-plus-misprediction vector. No additional state is needed, and the four boundary words above should anchor the shift and discard tests.

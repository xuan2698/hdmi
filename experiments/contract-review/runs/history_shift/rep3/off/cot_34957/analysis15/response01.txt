The register is a single 32-bit state element. Its only guaranteed initialization is via `areset`: when `areset` is high, the state becomes zero asynchronously (positive-edge triggered reset), and any value before that is unspecified. A checker should therefore treat the pre-reset value as unknown and only begin comparing `predict_history` after a reset has been observed. Because `areset` is asynchronous, an asserted reset takes effect immediately, not merely at the next sampled clock edge; the prose should note that a mid-row reset drives the state to zero before the next sample.

When `areset` is low, the register updates only at a sampled positive clock edge, and the update follows a strict priority chain. Highest priority is `train_mispredicted`: if asserted, the register loads `{train_history[30:0], train_taken}`. This represents the history before the mispredicted branch, shifted left by one, with the actual branch outcome inserted at the LSB. The `train_history` input is the full 32-bit pre-branch history; only its lower 31 bits are retained in the concatenation, and the oldest bit is discarded by the shift.

Second priority is `predict_valid`: if `train_mispredicted` is not asserted and `predict_valid` is asserted, the register shifts left and inserts `predict_taken` at the LSB, producing `{predict_history[30:0], predict_taken}`. Here `predict_history[0]` is the direction of the youngest branch, so the LSB is the most recent outcome and the MSB is the oldest.

If neither control is asserted, the register holds its current value. The coincident case—`train_mispredicted = 1` and `predict_valid = 1` in the same cycle—must resolve to the misprediction update. The pipeline flush that accompanies a misprediction also flushes the branch currently making a prediction, so the prediction shift must be suppressed. A checker that applies the prediction shift first, or that ranks `predict_valid` above `train_mispredicted`, will diverge precisely in this case; this is the most important edge case to test explicitly.

**Worked example.** After reset, history is zero. At one sampled edge with `predict_valid = 1`, `predict_taken = 1`, history becomes `32'h0000_0001`. At the next row, suppose `train_mispredicted = 1`, `train_taken = 0`, `train_history = 32'h0000_0001`, and simultaneously `predict_valid = 1`, `predict_taken = 1`. Misprediction wins, so the next history is `{32'h0000_0001[30:0], 1'b0} = 32'h0000_0002`, not the prediction-shifted value. If `areset` is asserted mid-row instead, the register becomes zero immediately and the next sampled edge starts from zero.

For the final checker, the essential point is to model the register as one 32-bit state updated by the priority chain reset, then `train_mispredicted`, then `predict_valid`, then hold, and to verify the coincident prediction-plus-misprediction case explicitly. No state beyond the 32-bit register is required.

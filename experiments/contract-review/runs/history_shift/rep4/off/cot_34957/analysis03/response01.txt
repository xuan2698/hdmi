The state is a single 32-bit history register, `predict_history`. Its value is observable as the registered output, and it changes only on the rising edge of `clk` (or asynchronously on assertion of `areset`). The checker should model this register explicitly and derive the expected output from it after each sampled edge.

At each rising edge, the update priority is: asynchronous reset first, then misprediction training, then prediction. If `areset` is asserted, the register becomes zero regardless of all other inputs. Otherwise, if `train_mispredicted` is asserted, the register is loaded with the concatenation of `train_history` and `train_taken`: the new bit 0 is `train_taken`, and bits 31:1 are `train_history[30:0]` (equivalently, `{train_history[30:0], train_taken}` for a 32-bit register). This represents the history before the mispredicted branch followed by the actual branch outcome. The prediction inputs are ignored in this case, even if `predict_valid` is also asserted, because the flush removes the in-flight prediction.

If neither reset nor misprediction is active and `predict_valid` is asserted, the register shifts left by one and inserts `predict_taken` at bit 0: new value is `{old_history[30:0], predict_taken}`. Bit 0 is the youngest branch direction. If none of these conditions hold, the register retains its value.

The output `predict_history` is simply the current register contents. Because the output is registered, the checker should compare the output sampled after a rising edge against the state computed from the inputs that were stable before that edge. Mid-cycle input changes occur after sampling and must not affect the just-sampled update; they are inputs for the next edge. A mid-cycle assertion of `areset`, however, is asynchronous: it must immediately force the reference state to zero and the expected output to zero, independent of the clock.

A useful point for the final checker is to separate the reference-state update from the output comparison. Maintain a reference history variable. On each sampled rising edge, first check whether `areset` was asserted (including any asynchronous assertion observed in the interim window); if so, set reference to zero. Otherwise apply misprediction priority, then prediction, then hold. Then compare the sampled `predict_history` to the reference. For mid-cycle changes, update the reference only for asynchronous reset; defer all other input effects to the next edge. This avoids the common error of applying a post-edge `predict_taken` or `train_history` change to the state that was just captured.

Worked example: suppose reference history is `0x0000_0000`. Before a rising edge, `predict_valid=1`, `predict_taken=1`, `train_mispredicted=0`. After the edge, reference becomes `0x0000_0001`, and the sampled output must match. If instead `train_mispredicted=1`, `train_taken=0`, and `train_history=0x8000_0000`, the prediction is ignored and reference becomes `{0x8000_0000[30:0], 0} = 0x0000_0000`; the checker must apply this priority before comparing. If `areset` asserts mid-cycle after the edge, reference and expected output immediately become zero.

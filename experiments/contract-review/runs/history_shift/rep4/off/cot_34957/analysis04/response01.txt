The public interface is a single 32-bit registered state element with a small set of one-bit control inputs. All control signals (`areset`, `predict_valid`, `predict_taken`, `train_mispredicted`, `train_taken`) are one bit wide, while `train_history` and `predict_history` are 32 bits wide. The clock is `clk`, and sampling is specified after the positive edge has settled. The protocol seed is 20261123, which is only relevant to stimulus generation and not to the functional contract.

The state is a 32-bit global branch history shift register. Bit 0 is the youngest branch direction, and bit 31 is the oldest retained direction. The output `predict_history` is the current register contents, so the checker should treat the output as a registered view of the reference state rather than as a combinational function of the current inputs.

Boundary values matter in three places. First, the shift operation `{old_history[30:0], predict_taken}` discards bit 31 and inserts the new direction at bit 0; the checker must not accidentally shift right or insert at bit 31. Second, the misprediction load uses `{train_history[30:0], train_taken}`, which also discards `train_history[31]` and places `train_taken` at bit 0. Third, the all-zero and all-one histories are legal and must round-trip correctly; for example, shifting a `0xFFFF_FFFF` history with `predict_taken=0` yields `0xFFFF_FFFE`, not zero.

Priority is the most important boundary condition. Asynchronous reset has the highest priority and is edge-triggered on assertion, not merely sampled at the clock edge. A misprediction (`train_mispredicted=1`) overrides a simultaneous prediction (`predict_valid=1`), because the pipeline flush removes the branch currently predicting. Prediction applies only when reset and misprediction are inactive and `predict_valid=1`. Otherwise the register holds.

The checker should maintain a reference history variable separate from the DUT output. On each sampled rising edge, first handle any observed asynchronous reset by forcing the reference to zero. Otherwise, if `train_mispredicted` was asserted before the edge, set the reference to `{train_history[30:0], train_taken}`. Else if `predict_valid` was asserted, set it to `{reference[30:0], predict_taken}`. Else leave it unchanged. Then compare the sampled `predict_history` against the reference.

Mid-cycle input changes are the subtle part. Changes occurring after sampling but before the next edge must not retroactively alter the state just captured. The checker should defer all non-reset mid-cycle changes to the next edge. The one exception is `areset`: an asynchronous assertion observed in the interim window must immediately force both the reference state and the expected output to zero, independent of the clock.

Worked example: start with reference `0x0000_0000`. Before an edge, `predict_valid=1`, `predict_taken=1`, `train_mispredicted=0`. After the edge the reference becomes `0x0000_0001`, and the sampled output must match. If instead `train_mispredicted=1`, `train_taken=0`, and `train_history=0x8000_0000`, prediction is ignored and the reference becomes `{0x8000_0000[30:0], 0} = 0x0000_0000`. The checker must apply this priority before comparing. If `areset` asserts mid-cycle after the edge, reference and expected output immediately become zero.

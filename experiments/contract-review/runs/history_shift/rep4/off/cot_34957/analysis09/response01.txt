The state is a single 32-bit global branch-history register. Its value is observable as `predict_history`, and it changes only in response to the sampled clock edge or the asynchronous reset. The checker should maintain a reference copy of this register and update it in the same order the hardware does: reset first, then misprediction training, then ordinary prediction, then hold.

At each sampled rising edge, inspect `areset` before anything else. If `areset` is asserted, the reference history becomes zero and the sampled `predict_history` must also be zero. This reset has priority over every other input, including `predict_valid`, `predict_taken`, `train_mispredicted`, `train_taken`, and `train_history`. Because the reset is asynchronous, the checker should also react to a rising `areset` between sampled edges: as soon as `areset` is observed high, the reference should be forced to zero, and it should remain zero until reset is released and a later edge applies a normal update. This matters for tests that toggle reset in the middle of a cycle.

When `areset` is low at the sampled edge, the next-state logic is a priority chain. First, if `train_mispredicted` is high, the misprediction wins over any simultaneous prediction. The new history is formed from the lower 31 bits of `train_history` shifted left, with `train_taken` placed in bit 0: `{train_history[30:0], train_taken}`. The upper bit of `train_history` is discarded, and `predict_taken` is ignored even if `predict_valid` is also high. This models the pipeline flush: the branch currently predicting is flushed, so its speculative history bit must not survive.

Second, if `train_mispredicted` is low and `predict_valid` is high, the register shifts in the predicted direction. The new value is `{old_history[30:0], predict_taken}`. Here `old_history` is the reference value before this edge update, not the newly trained value. Bit 0 of the result is the youngest branch direction, as required by the specification.

Third, if neither `train_mispredicted` nor `predict_valid` is asserted, the history holds its previous value. No other input affects the state in that case.

The output `predict_history` is simply the current register value. After a sampled edge, the checker should compare the observed 32-bit output against the reference computed by the priority chain above. All 32-bit patterns are valid, so the checker must not reserve any value as an “unknown” sentinel. Before the first reset, the specification does not define power-up history; the checker should initialize its reference to zero and treat the first observed reset as authoritative. If the testbench starts with `areset` already high, the reference should be zero before the first sampled edge.

A short worked example: with reference history `0x1234_5678`, an edge with `areset=0`, `predict_valid=1`, `predict_taken=1`, and `train_mispredicted=0` yields `0x2468_ACF1`. If `areset` then rises before the next edge, the reference becomes zero immediately. If instead `train_mispredicted=1` and `predict_valid=1` occur together, the checker uses `{train_history[30:0], train_taken}` and ignores `predict_taken`.

The interface is a single 32-bit state register with five one-bit controls and one 32-bit training input. All control inputs are scalar: `areset`, `predict_valid`, `predict_taken`, `train_mispredicted`, and `train_taken` are each 1 bit, while `train_history` and the output `predict_history` are 32 bits. Because the state is exactly 32 bits, every legal next-state expression must produce a 32-bit value; there is no wider intermediate that survives. The only arithmetic-like operation is concatenation and truncation, so boundary behavior is about which bit is discarded and which bit is inserted, not about overflow or signedness.

The register is positive-edge triggered, and `areset` is asynchronous and active high. Sampling occurs after the posedge has settled, so the checker should compare the post-edge value of `predict_history`. The asynchronous reset means a reset assertion between edges must affect the output without waiting for a clock edge; a purely synchronous reset implementation can pass many ordinary rows but will fail a between-edge reset stimulus. The reset value is all zeros, so the boundary state after reset is `32'h0000_0000`.

The three update modes are mutually prioritized. Reset has highest priority and forces zero. Next, `train_mispredicted` loads the rollback value `{train_history[30:0], train_taken}`. This is a 32-bit result: the oldest bit of `train_history` (bit 31) is discarded, bits 30 down to 0 move up by one position, and `train_taken` becomes bit 0. The current `predict_history` is irrelevant in this mode, and so are `predict_valid` and `predict_taken`. This is the key rollback behavior: the register is not shifted from its current value; it is overwritten from the supplied pre-branch history plus the actual branch result.

When reset and misprediction are both low and `predict_valid` is high, the next state is `{predict_history[30:0], predict_taken}`. Bit 0 is the youngest branch, so the predicted direction enters at the least significant end and the oldest history bit falls off the top. When no control is active, the register holds its value. If `predict_valid` and `train_mispredicted` are both high, misprediction wins, because the flush removes the branch currently predicting.

A compact worked example: suppose the current register is `32'hA5A5_5A5A`. On an edge with `areset=0`, `train_mispredicted=1`, `predict_valid=1`, `predict_taken=1`, `train_history=32'h0000_0003`, and `train_taken=0`, the next value is `{32'h0000_0003[30:0], 1'b0} = 32'h0000_0006`. The prediction is ignored. If `areset=1` on that same edge, the next value is `32'h0000_0000`.

For the final Python checker, the most useful focus is priority and timing rather than broad random coverage. Include an asynchronous reset asserted between edges with no clock activity and sampled before the next posedge; a coincident reset-plus-predict-plus-mispredict edge that must yield zero; a post-reset prediction edge that must place `predict_taken` in bit 0 with the upper 31 bits zero; a misprediction-only edge that confirms the exact concatenation order and the dropped top bit of `train_history`; and a hold edge that confirms no spurious update. Vary reset timing relative to the clock to expose synchronous-only reset logic, and never assume a power-up value: establish state through reset or a known transition before comparing.

**Reset and power-up behavior**

The specification defines `areset` as a positive-edge-triggered asynchronous reset that clears the 32-bit global history shift register to zero. Two properties matter for the checker. First, the reset is asynchronous: assertion of `areset` need not wait for a clock edge to take effect, so the register may be forced to zero at any time while `areset` is high. Second, the reset is positive-edge triggered in the sense that the sampled value after a rising clock edge with `areset` asserted must be zero. In practice, the checker should treat any sampled edge where `areset = 1` as producing `predict_history = 0` after the edge has settled, regardless of what the other inputs are doing on that edge. The reset has priority over every other update path: prediction and misprediction inputs are ignored while reset is asserted.

Power-up behavior is not separately specified beyond the reset. The register has no defined initial value before the first reset or before the first sampled edge that establishes state. A checker should therefore not assume any particular value at time zero; it should either begin comparison only after an asserted reset has been observed, or seed its reference model from the first post-reset sample. Because the protocol description says each row's values are driven before the sampled edge and optional mid-input changes occur after sampling, the checker should also ensure that a mid-cycle change to `areset` is not retroactively applied to the just-sampled edge. Only the value present at the sampled edge governs that edge's result; a later change belongs to the next row.

The priority order for a non-reset edge is: misprediction first, then prediction, then hold. When `train_mispredicted = 1`, the register loads the post-branch history formed from `train_history` and `train_taken`, and any simultaneous `predict_valid` is discarded because the pipeline flush removes the predicting branch. When `train_mispredicted = 0` and `predict_valid = 1`, the register shifts left by one and inserts `predict_taken` at bit 0, with bit 0 being the youngest branch. When neither is asserted, the register holds its value.

A useful point for the final Python checker is to model reset as an unconditional override evaluated before the priority chain, and to model the shift direction explicitly with LSB-youngest semantics. For example, if the current history is `0x0000_0001` and a sampled edge has `predict_valid = 1`, `predict_taken = 1`, and no misprediction, the next value is `0x0000_0003`. If that same edge instead has `train_mispredicted = 1`, `train_taken = 0`, and `train_history = 0x0000_0003`, the misprediction wins and the next value is `0x0000_0006`. Encoding these cases directly, with reset checked first and mid-input changes deferred to the next row, captures the public behavior without relying on unstated power-up assumptions.

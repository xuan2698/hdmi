The register is a 32-bit global branch history shift register. Its state is the 32-bit vector `predict_history`, which is also the sole output. The youngest branch direction occupies bit 0; older directions occupy progressively higher bits. The register is updated only on the rising edge of `clk`, and the sampled value of each input at that edge determines the next state. Inputs that change after the sampled edge belong to the following row and must not affect the just-sampled transition.

Reset is the highest-priority override. When the sampled `areset` is 1, the register is asynchronously cleared to zero, regardless of any other input. Because reset is asynchronous and positive-edge triggered, an asserted `areset` forces the state to zero without waiting for a clock edge; the checker should treat reset as an unconditional override evaluated before the normal priority chain. Inputs are ignored while reset is asserted. Power-up state is unspecified, so the checker should not assume any initial value before a reset has been observed or before the first sampled edge establishes state; it should seed its reference model from the first post-reset sample.

For a non-reset sampled edge, the priority order is: misprediction, then prediction, then hold. If `train_mispredicted = 1`, the register loads the post-branch history formed by concatenating `train_history` with the actual branch outcome `train_taken`. Concretely, the new value is `(train_history << 1) | train_taken`, truncated to 32 bits, so `train_taken` becomes the new bit 0 and the previous `train_history` bits shift up by one. This represents the history after completion of the mispredicted branch: the history before that branch followed by its actual direction. Any simultaneous `predict_valid` is discarded, because the pipeline flush removes the branch currently making the prediction. If `train_mispredicted = 0` and `predict_valid = 1`, the register shifts left by one and inserts `predict_taken` at bit 0: new value is `(predict_history << 1) | predict_taken`, truncated to 32 bits. If neither is asserted, the register holds its current value.

The checker should model reset first, then the misprediction branch, then the prediction branch, then hold. It should also defer mid-cycle input changes: only the value present at the sampled edge governs that edge, and a later change to `areset` or any other input applies to the next row. This prevents a mid-cycle reset assertion from retroactively zeroing the just-sampled result.

Worked example: suppose the current history is `0x0000_0001`. If a sampled edge has `predict_valid = 1`, `predict_taken = 1`, and no misprediction, the next value is `0x0000_0003`. If instead that same edge has `train_mispredicted = 1`, `train_taken = 0`, and `train_history = 0x0000_0003`, the misprediction wins and the next value is `0x0000_0006`. Encoding these cases directly, with reset checked first and mid-input changes deferred to the next row, captures the public behavior without relying on unstated power-up assumptions.

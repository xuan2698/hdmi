The key distinguishing case for the checker is the first `1` in the stream, because that is the only row where the Moore output and the transition disagree in a way that a naive checker can get wrong. In `S0`, the machine outputs `z=0` regardless of `x`. When `x=1` arrives, the transition goes to `S1`, and the output for that row must be the output of `S1`, namely `z=1`. A checker that samples `z` from the pre-edge state would report `0` for that row and would then be off by one for the entire remaining stream. This is the single most likely implementation error, and it is worth an explicit test vector.

Consider the LSB-first stream `0,1,0` (the three-bit value 2). Row 1: `x=0`, state `S0`, next state `S0`, sampled `z=0`. Row 2: `x=1`, state `S0`, next state `S1`, sampled `z=1`. Row 3: `x=0`, state `S1`, next state `S1`, sampled `z=1`. The output stream is `0,1,1`, which is 3, the three-bit two's complement of 2. The middle row is the discriminator: pre-edge state is `S0` (output 0), post-edge state is `S1` (output 1), and the correct answer is 1. Any checker that binds `z` to the pre-edge state fails exactly here and nowhere else in this example, which is why this short vector is the most economical distinguishing test.

Two further boundaries deserve attention in the same pass. First, the all-zero stream: every row stays in `S0`, so every output is `0`, which is the correct two's complement of zero at any width. A checker must not require a `1` to appear before accepting outputs. Second, reset assertion mid-stream: because reset is asynchronous, asserting `areset` must force `S0` and `z=0` immediately, discarding any pending transition, and the checker must not wait for a posedge to observe that state. Release then restarts conversion from `S0`, so a stream that is interrupted and restarted is treated as a fresh number rather than a continuation.

The mid-row input change rule matters for the checker's timing model: an `x` change after sampling is carried to the next row and must not retroactively alter the transition or output already committed for the sampled edge. Combined with post-edge output binding and immediate reset override, these three rules — post-edge `z`, immediate reset, deferred mid-row `x` — are the complete set of temporal decisions the final checker must encode. The worked example above isolates the first of them; the all-zero and mid-stream-reset cases isolate the other two.

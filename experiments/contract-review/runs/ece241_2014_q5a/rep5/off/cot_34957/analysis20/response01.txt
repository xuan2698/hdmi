**Reset and power-up behavior.** The machine has no meaningful power-up state. Before the first assertion of `areset`, the state register may come up in any value, and the Moore output `z` is simply whatever that unknown state decodes to. The public specification does not promise a defined `z` at power-up, and the checker must not sample or compare `z` until reset has been asserted and released. Assertion of `areset` is asynchronous: it must force the state to `S0` immediately, without waiting for a positive `clk` edge, and it must clear any partial conversion in progress. Because the conversion is LSB-first and the machine must remember whether it has already seen the first `1`, reset is the only mechanism that re-arms that memory. Releasing `areset` starts a fresh conversion at `S0`; the first post-release positive edge is the first edge whose consumed `x` bit and settled `z` are both meaningful for comparison.

The checker-critical consequence is the phase relationship. Each row drives `x` before the sampled positive edge; `z` is sampled after that edge has settled. Since the machine is Moore, `z` is a function of the post-edge state, and that state was updated using the `x` present at that same edge. So for a row with input bit `x_i`, the output `z_i` belongs to the edge that consumed `x_i` — it is the registered state output, not a one-cycle-lagged combinational function of `x`. The checker must align `z_i` with that same edge, not the following one. A mid-row change on `x` occurs after sampling and belongs to the next row; it must not retroactively alter the current row's settled `z`. Because `z` is Moore, it is constant within a row once the edge settles, so any mid-row change on `z` is a defect.

**Worked example.** Input stream `0,1,0` LSB-first yields output `0,1,1`. Row 1: `x=0`, state stays `S0`, `z=0`. Row 2: `x=1`, state moves to `S1`, `z=1`. Row 3: `x=0`, state stays `S1`, `z=1`. A checker that reads `z` before the edge, or derives `z` combinationally from current `x`, produces `0,0,1` — an off-by-one error invisible on all-zero streams and appearing only after the first `1`. The all-zero stream is the clean boundary: the machine never leaves `S0`, every `z` is `0`, and no transition to `S1` should be observed.

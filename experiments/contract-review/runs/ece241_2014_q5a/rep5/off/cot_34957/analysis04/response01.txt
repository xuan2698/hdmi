The public interface is narrow but the timing semantics are where a checker usually goes wrong. `areset`, `x`, and `z` are each one bit; `clk` is the only clock. There are no multi-bit buses, no enables, and no output valid flag, so every sampled row produces exactly one output bit and every row is meaningful while reset is released. Boundary values are therefore trivial in width but not in meaning: `x ∈ {0,1}`, `z ∈ {0,1}`, and `areset ∈ {0,1}`. The interesting boundaries are temporal, not numeric — the first row after reset release, the all-zero input stream, the first `1` encountered (which is copied rather than complemented), and the moment reset is asserted mid-stream.

The machine has two states. `S0` is the pre-first-one state and outputs `z=0`; `S1` is the post-first-one state and outputs `z=1`. Because this is Moore, the output is a function of the state alone, and the checker must read `z` from the state occupied after the sampled edge, not from the state before it. That single decision determines whether the transition table and output table agree. From `S0`, `x=0` stays in `S0` and `x=1` goes to `S1`. From `S1`, both input values stay in `S1`. The output attached to the entered state then automatically gives the right bit: a leading zero is copied as zero, the first one is copied as one, and every later bit is complemented because `S1` always outputs one. The all-zero stream never leaves `S0` and outputs all zeros, which is the correct two's complement of zero for any width.

Reset is asynchronous and positive-edge triggered for normal operation. Assertion must force `S0` and `z=0` immediately, without waiting for a clock edge; the checker should evaluate reset before any transition and should not require a posedge to observe the reset state. Release begins conversion from `S0`. A mid-row change on `x` occurs after sampling and is carried to the next row; it must never retroactively alter the transition or output already committed for the sampled edge. If reset is asserted during a row, the pending transition is discarded and the reset state is reported.

Worked example, LSB-first input `0,1,0` (value 2 over three bits): row 1 `x=0`, `S0→S0`, `z=0`; row 2 `x=1`, `S0→S1`, `z=1`; row 3 `x=0`, `S1→S1`, `z=1`. Output stream `0,1,1` equals 3, the three-bit two's complement of 2. The useful point for the final checker: bind `z` to the post-edge state and treat reset as an immediate override, so the transition function, output function, and sampling order cannot disagree.

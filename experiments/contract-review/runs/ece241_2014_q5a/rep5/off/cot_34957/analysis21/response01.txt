The machine has two states, `S0` and `S1`, with Moore output `z` decoded as `0` in `S0` and `1` in `S1`. `S0` is the "no `1` seen yet" state; `S1` is the "first `1` already seen" state. The input is consumed least-significant bit first, so the 2's-complement rule is: copy bits until and including the first `1`, then invert every subsequent bit. `S0` implements the copy phase, `S1` implements the invert phase.

Transitions from `S0`: on `x=0`, remain in `S0` and output `0` (copy the zero). On `x=1`, move to `S1` and output `1` (copy the first one, and arm inversion for later bits). Transitions from `S1`: on `x=0`, remain in `S1` and output `1` (invert zero to one). On `x=1`, remain in `S1` and output `0` (invert one to zero). Thus `S1` is absorbing: once the first `1` arrives, every later bit is inverted regardless of its value, and the machine never returns to `S0` except through reset. The all-zero stream is the boundary case: it never leaves `S0`, so every output is `0` and no `S0→S1` transition should ever be observed.

Reset is asynchronous and active-high (`areset`). Asserting it forces the state to `S0` immediately, independent of `clk`, clearing any partial conversion and re-arming the "first `1` not yet seen" memory. Releasing `areset` begins a fresh conversion from `S0`. Power-up state is unspecified by the public spec, so `z` is undefined until reset has been asserted and released; the checker must not sample or compare `z` before that.

The checker-critical point is phase alignment. Each row drives `x` before the sampled positive edge; `z` is sampled after that edge settles. Because the machine is Moore, `z` is a function of the post-edge state, and that state was updated using the `x` present at the same edge. Therefore the output `z_i` in a row belongs to the edge that consumed `x_i` — it is the registered state output for that same edge, not a one-cycle-lagged function of `x`. The checker must align `z_i` with the edge that consumed `x_i`, not the following edge. A mid-row change on `x` occurs after sampling and belongs to the next row; it must not retroactively alter the current row's settled `z`. Since `z` is Moore, it is constant within a row once the edge settles, so any mid-row change on `z` is a defect.

Worked example: input stream `0,1,0` LSB-first yields output `0,1,1`. Row 1: `x=0`, stay `S0`, `z=0`. Row 2: `x=1`, move to `S1`, `z=1`. Row 3: `x=0`, stay `S1`, `z=1`. A checker that reads `z` before the edge, or derives `z` combinationally from current `x`, yields `0,0,1` — an off-by-one error invisible on all-zero streams and appearing only after the first `1`. The final Python checker should therefore compare each row's settled `z` against the state reached by consuming that row's `x`, and should ignore `z` entirely until reset has been asserted and released.

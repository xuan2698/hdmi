The machine's state must encode how much of the 2's-complement conversion has already been determined. Reading the input LSB-first, the standard serial algorithm is: copy bits unchanged until the first `1` is seen, then invert every subsequent bit. So the natural Moore state set is two states — call them `S0` (no `1` seen yet, still in the "copy" phase) and `S1` (a `1` has been seen, now in the "invert" phase). The output `z` is a pure function of the state: in `S0`, `z = x` conceptually, but since Moore outputs cannot depend on the current input, the output must be attached to the state that will be occupied after the edge. This is the key design decision the checker must respect: the Moore output is read from the post-edge state, so the transition function and output function must be defined consistently.

Transitions: from `S0`, if `x = 0`, remain in `S0` (bit copied as 0, output 0). If `x = 1`, move to `S1` (this first 1 is copied as 1, so the state entered must output 1). From `S1`, regardless of `x`, remain in `S1`, and the output is the complement of the sampled bit — but again, because it is Moore, the output is fixed by the state. The clean way to resolve this is to let the output be associated with the state *after* the transition, and to define the transition so that the entered state's output equals the required 2's-complement bit for that sample. Concretely: `S0` outputs 0; `S1` outputs 1. Then from `S0` with `x=0` go to `S0` (output 0, correct copy of 0); from `S0` with `x=1` go to `S1` (output 1, correct copy of the first 1); from `S1` with `x=0` go to `S1` (output 1, correct inversion of 0); from `S1` with `x=1` go to `S1` (output 1, correct inversion of 1). This yields the correct stream for any length, including the all-zero case (stays in `S0`, outputs all zeros, which is the 2's complement of zero).

Reset: asynchronous assertion forces the machine to `S0` immediately, with `z = 0`, independent of clock. The checker must apply reset before evaluating any edge transition, and must not require a posedge to observe the reset state. When reset is released, conversion begins from `S0` on the next sampled bits.

Worked example: input bits LSB-first `0, 1, 0` (number 010 = 2). Row 1: `x=0`, state `S0`→`S0`, `z=0`. Row 2: `x=1`, `S0`→`S1`, `z=1`. Row 3: `x=0`, `S1`→`S1`, `z=1`. Output stream `0,1,1` = 3, the 2's complement of 2 over three bits. If `areset` is asserted during row 2, the checker must immediately report `S0`/`z=0` and discard the pending transition; a mid-row `x` change is queued for the next row and never alters the already-sampled transition or output.

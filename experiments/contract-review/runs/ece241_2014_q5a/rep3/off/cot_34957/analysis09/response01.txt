The machine has two states: COPY and INVERT. In COPY, the machine has not yet seen a 1 in the input stream; it passes each input bit straight through to the output (z = x) and stays in COPY while x = 0. On the first x = 1, the output is still z = 1 (the bit is copied), and the machine transitions to INVERT. In INVERT, every subsequent bit is complemented: z = ~x, and the machine remains in INVERT regardless of x. This is the standard LSB-first 2's complement algorithm: copy bits up to and including the first 1, then invert all higher bits. The reset state is COPY, so after reset is released the machine is ready to copy leading zeros.

The critical timing point for the checker is Moore alignment combined with reset dominance. At each posedge, the checker must first honor areset: if areset = 1 on the sampled row, the state is forced to COPY and z is the COPY output for that row (z = 0, since COPY with no input history outputs the copied bit — but under reset the output must be the reset-state output, i.e., z = 0). Reset dominates both the state update and the output; a design that updates state unconditionally or gates only the output will diverge here. If areset = 0, the checker computes z from the pre-edge state (COPY → z = x; INVERT → z = ~x), then updates the state using x: COPY with x = 1 → INVERT; COPY with x = 0 → COPY; INVERT → INVERT. Mid-row changes to x or areset occur after sampling and apply only to the next row; they must never retroactively change the just-sampled z or the transition.

The highest-value assertion is the first-1 boundary. On the row where x = 1 first appears while in COPY, z must be 1 (copied), and the next state must be INVERT. A design that computes the output from the post-transition state would emit z = 0 on that boundary row — the classic bug. Because later rows in a typical trace also output 1, a checker that skips the boundary row can still pass a broken design, so the boundary must be asserted explicitly.

Worked example: input 0100 LSB-first (value 2). Row 1: areset released, state COPY, x = 0 → z = 0, next COPY. Row 2: x = 1 → z = 1 (boundary), next INVERT. Row 3: x = 0, INVERT → z = 1. Row 4: x = 0, INVERT → z = 1. Output 0011 LSB-first = 3, the 2's complement of 2. The boundary row (row 2) is where a post-transition-output bug shows z = 0 instead of 1.

For the final checker: require an initial reset row (or treat the first row's state as unconstrained), enforce reset dominance on every row with areset = 1, evaluate z from the pre-edge state before applying the x-driven transition, carry mid-row changes forward only, and explicitly assert the first-1 boundary row.

The port widths are minimal and unambiguous: `areset` and `x` are each one bit, `z` is one bit, and `clk` is the single sampling clock. Because the machine is a Moore machine, `z` is a function of the pre-edge state alone, not of the current row's `x`. That single fact drives every boundary decision in the checker.

The state space has exactly two meaningful states: COPY and INVERT. In COPY, the machine has not yet seen the first `1` of the LSB-first stream, so the output equals the latched input bit (the bit that was sampled on the previous row). In INVERT, the first `1` has been seen, so the output is the complement of the latched bit. Reset forces the machine into COPY with the reset output value, and while `areset` is asserted, `x` is ignored entirely.

The critical boundary is the transition row — the row on which the first `1` arrives. On that row the pre-edge state is still COPY, so `z` must reflect the COPY-phase output (the previously latched bit), even though the state update consumes that row's `x` and moves the machine to INVERT. A checker that computes `z` from the current row's `x` will be correct on every row except this one, which makes the defect easy to overlook in short traces. The correct order is: reset dominance, then Moore output from pre-edge state, then state update from the row's `x`.

Mid-row changes are deferred. An `x` change after the sampling edge belongs to the next row and must never be applied retroactively. The same deferral applies to `areset`: a mid-row assertion affects only the next sampled row and cannot rewrite an already-sampled output or state. Each row is a snapshot taken after the positive edge has settled.

Worked example: release reset, then feed LSB-first `0, 1, 0, 1`. Row 1 (`x=0`): pre-edge COPY, output is the COPY output, state stays COPY. Row 2 (`x=1`): pre-edge COPY, so output is again the COPY output, but state updates to INVERT. Row 3 (`x=0`): pre-edge INVERT, output is the complement of the latched bit, state stays INVERT. Row 4 (`x=1`): output is again the INVERT-phase output. Any row with `areset=1` forces reset state and reset output and ignores `x`.

For the final checker, the useful point is strict ordering: reset dominance first, Moore alignment second (compute `z` from pre-edge state, then update state from `x`), deferred mid-row changes third. Sampling occurs after the positive edge has settled, so any output that would only be correct if `z` tracked `x` combinationally within the same row must be rejected.

The key timing point for the checker is the Moore output convention: `z` must be sampled from the state *after* the current row's transition, not from the state that was present before the edge. In this design the state register is updated on the positive edge, and the output is taken from that register, so the row that first sees `x=1` already reports `z=1`. A checker that computes `z` from the pre-transition state will agree only while the machine is in S0 (where the next state is also S0) and will diverge from the first `1` onward.

The correct invariant is: sample `x` and `areset`, compute the next state, install it, then emit `z` from the installed state. Equivalently, `z` on row *n* reflects the state after row *n*'s transition. This is the Moore definition and matches hardware where the output is taken from the state register after the clock edge.

A short worked example makes the failure concrete. Take LSB-first `x = 0,1,0,1`, representing 10; its two's complement is 0110, so the LSB-first output should be `0,1,1,0`. Row 1: state S0, `x=0`, next state S0, `z=0`. Row 2: state S0, `x=1`, next state S1, `z=1` — the distinguishing row. Row 3: state S1, `x=0`, next state S1, `z=1`. Row 4: state S1, `x=1`, next state S1, `z=0`. A pre-state checker instead yields `0,0,1,1`, wrong from row 2. Note also that S1 is absorbing until reset: once the first `1` is seen, every later row outputs `z=1` regardless of `x`, so the checker must not try to recompute the complement per bit or toggle on `x` alone.

The reset boundary compounds this if handled loosely. `areset` is positive-edge triggered and asynchronous, but the checker samples it after the posedge has settled. A sampled-high `areset` forces S0 with `z=0` for that row and must not consume the `x` bit; conversion begins on the first row where `areset` is sampled low. A reset asserted after the sampled edge takes effect on the next row. Mid-row `x` changes are staged and carried to the start of the next row, so they never affect the current row's sampled value. The reference should therefore be anchored at the first sampled-high reset row, not at time zero, and the input index should advance only on rows where `areset` is sampled low. Combined with the post-transition output rule, these two invariants — emit `z` after installing the next state, and advance the input index only on non-reset rows — cover the failure modes a naive checker is most likely to exhibit.

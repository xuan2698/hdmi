The machine is a Moore machine, so its output depends only on the current state, not directly on the input. The state must remember whether a `1` has already been encountered in the LSB-first stream. Until the first `1` arrives, the output is simply the input bit itself (since the 2's complement of a number with no lower-order `1` yet is just the bit unchanged). After the first `1`, every subsequent bit is inverted, because the 2's complement algorithm is: copy bits up to and including the first `1`, then invert all higher-order bits.

Two states suffice. Call them S0 ("no 1 seen yet") and S1 ("a 1 has been seen"). In S0, output `z = 0`; the machine stays in S0 while `x = 0` and moves to S1 when `x = 1`. In S1, output `z = 1`; the machine remains in S1 for both input values, since once the first `1` is passed, all remaining bits are inverted regardless of their value. The Moore output is therefore `z = 0` in S0 and `z = 1` in S1.

Reset is asynchronous and level-sensitive: while `areset` is high, the state is forced to S0 and `z = 0` independent of the clock. On release, the machine holds S0 (and `z = 0`) until the first positive edge. That first post-reset edge samples `x` and transitions according to the table above; only after that edge can `z` become 1 (if the sampled bit was 1). The checker must not expect a converted output on the release edge itself, nor treat the interval between release and the first edge as having consumed a bit.

At each sampled positive edge, the checker should latch `x`, compute the next state from the current state and latched `x`, then compare `z` to the Moore output of the resulting state. Mid-row changes to `x` (after sampling, before the next edge) belong to the next row and must not alter the current row's `z`.

Worked example: release reset, drive LSB-first `x = 0,1,0,1`. Row 1 samples 0: stay S0, `z=0`. Row 2 samples 1: go to S1, `z=1`. Row 3 samples 0: stay S1, `z=1`. Row 4 samples 1: stay S1, `z=0`. Output `0,1,1,0` is the 2's complement of input value 10, giving 6.

Key point for the final checker: model reset as a level-sensitive override forcing S0 and `z=0` whenever `areset` is high; on release hold S0 until the next sampled edge; at each edge latch `x`, update state, and compare `z` to the new state's Moore output, ignoring mid-row `x` changes for the current row.

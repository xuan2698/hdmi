The public interface is narrow: one 1-bit input `x`, one 1-bit output `z`, one clock `clk`, and one asynchronous reset `areset`. All data ports are single-bit, so there are no multi-bit boundary values to interpret; the only meaningful values are 0 and 1. The state machine is a Moore machine, meaning `z` is a function of the current state alone, not of the current input. The input stream is presented least-significant bit first, and the output stream is the 2's complement of the input number, also produced least-significant bit first.

The conversion rule is: copy input bits up to and including the first `1`, then invert every subsequent bit. This gives two states: Copy and Complement. In Copy, `z=0`. In Complement, `z=1`. The first sampled `1` causes the transition from Copy to Complement, and because the machine is Moore, the output on that same sampled edge must already be the output of the new state, namely `1`. This same-edge alignment is the most important boundary condition for the checker.

Reset is asynchronous and positive-edge triggered in the sense that assertion forces the machine to Copy and forces `z=0`. While `areset` is asserted, `x` is unconstrained and may change freely; the checker should not require any particular input value or any fixed number of idle cycles during reset. When reset is released, the machine begins conversion from Copy. The first positive edge after release that samples `x` participates normally: if `x=0`, the machine remains in Copy with `z=0`; if `x=1`, the machine enters Complement and the sampled `z` must be `1` on that same edge.

A short worked example clarifies the timing. Suppose after reset release the sampled input sequence is `x = 0, 0, 1, 0, 1`. The expected sampled output sequence is `z = 0, 0, 1, 1, 0`. The first two zeros leave the machine in Copy with `z=0`. The third sample is the first `1`; the machine transitions Copy → Complement, and the output sampled on that same edge is `1`. The fourth sample `0` is inverted to `1`, and the fifth sample `1` is inverted to `0`. A checker that instead expects `z=0` on the edge that samples the first `1`, and `z=1` only on the following edge, is off by one cycle and will reject a correct Moore implementation.

For the final Python checker, the useful discipline is to maintain one reference state initialized to Copy. On each positive edge with `areset` deasserted, update the reference state from the sampled `x`, then compare the sampled `z` to the Moore output of the updated state on that same edge. When `areset` is asserted, force the reference state to Copy and require `z=0`, without imposing idle-cycle requirements before or after release. Do not assume a particular state encoding or state count; only the Copy/Complement distinction and same-edge output alignment matter. The essential invariant is that input sampling, state transition, and Moore output observation are aligned to the same positive edge, with `z` reflecting the next state entered by that edge.

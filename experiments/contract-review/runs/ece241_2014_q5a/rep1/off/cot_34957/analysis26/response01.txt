A checker must align the Moore output with the state entered on the same positive edge, not the prior state. Initialize the reference state to Copy. On each sampled edge with `areset` deasserted, first update the reference state from sampled `x` (Copy stays Copy on `x=0`, goes to Complement on `x=1`; Complement stays Complement), then compare sampled `z` to that updated state's output (Copy→0, Complement→1). On `areset` asserted, force Copy and require `z=0`; do not constrain `x` or idle cycles during reset. Release begins conversion from Copy, and the first sampled edge after release participates normally.

Worked example: after release, `x = 0,0,1,0,1` yields `z = 0,0,1,1,0`. The third edge samples the first `1`, transitions Copy→Complement, and must show `z=1` on that same edge. A checker expecting `z=1` only on the next edge is off by one.

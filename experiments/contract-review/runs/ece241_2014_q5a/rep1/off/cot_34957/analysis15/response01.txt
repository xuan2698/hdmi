The machine has two Moore states, which we can call **Copy** (the initial state after reset) and **Complement**. The output `z` is a pure function of the current state: `z=0` in Copy and `z=1` in Complement. There are no Mealy-style output dependencies on the current input, so the output observed after a positive edge is determined solely by the state entered on that edge.

**Reset behavior.** While `areset` is asserted, the machine is held in Copy and `z=0`. Because reset is asynchronous and positive-edge triggered, the checker should treat assertion of `areset` as immediately forcing the reference state to Copy and the expected output to `0`. Input `x` is don't-care during reset; it may toggle freely without affecting the state or output. When `areset` is released, the next positive clock edge samples the first input bit and performs the first real transition.

**Copy state transitions.** In Copy, the machine is still reproducing the low-order zeros of the input. If the sampled `x=0`, the machine stays in Copy and `z` remains `0`. If the sampled `x=1`, the machine transitions to Complement, and because the Moore output is associated with the state entered by that same edge, `z` becomes `1` immediately on that edge—not one cycle later. This same-edge alignment is the critical point for the final checker.

**Complement state transitions.** Once the first `1` has been seen in LSB-first order, every remaining higher-order bit must be inverted to form the 2's complement. In Complement, a sampled `x=0` produces `z=1`, and a sampled `x=1` produces `z=0`. The machine never returns to Copy except via reset, because the first `1` permanently establishes that all subsequent bits are in the complement region. Thus Complement is absorbing under normal operation.

**Worked example.** Suppose reset is released and the sampled input sequence is `x = 0, 0, 1, 0, 1`. The expected sampled outputs are `z = 0, 0, 1, 1, 0`. The first two zeros keep the machine in Copy, so `z` stays `0`. The first `1` moves to Complement and yields `z=1` on that same edge. The following `0` is inverted to `1`, and the final `1` is inverted to `0`. A checker that expects the complementing output one cycle later, or that compares `z` to a function of the previous input, will report false failures.

**Guidance for the final Python checker.** Model the reference with a single two-valued state variable initialized to Copy. On each sampled positive edge: if `areset` is asserted, force the reference state to Copy and require `z=0`; otherwise update the reference state from the sampled `x` using the transitions above, then compare the sampled `z` to the Moore output of the updated state. Do not assume a particular state encoding or state count, allow `x` to change arbitrarily while `areset=1`, and avoid over-constraining the exact cycle of reset release. The essential invariant is that input sampling and Moore output observation are aligned on the same positive edge.

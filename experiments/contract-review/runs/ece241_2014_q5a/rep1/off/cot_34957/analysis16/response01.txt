The public interface is one bit in and one bit out: `areset` and `x` are each 1 bit wide, `z` is 1 bit wide, and `clk` is the single sampling clock. Because all data ports are scalar, there are no multi-bit boundary values to interpret; the only meaningful values are 0 and 1. The important boundary is temporal rather than numeric: `areset` is positive-edge-triggered and asynchronous, so it may be asserted or released between clock edges, and the machine must be forced into its reset behavior whenever the sampled edge sees `areset=1`. The specification says conversion begins when Reset is released and stops when Reset is asserted, so the checker should treat reset as a sampled control at each positive edge rather than requiring a particular number of idle cycles before or after release.

The machine is a Moore machine, so `z` depends only on the current state, not directly on `x`. The two states are naturally described as Copy and Complement. In Copy, the machine is still reproducing the low-order zeros of the LSB-first input. If the sampled `x=0`, the machine remains in Copy and `z=0`. If the sampled `x=1`, the machine enters Complement, and the Moore output associated with that entered state is `1` on that same edge. This same-edge alignment is the critical point for the final checker: the first `1` in the input is not delayed by one cycle in the output.

In Complement, every higher-order bit is inverted. A sampled `x=0` gives `z=1`, and a sampled `x=1` gives `z=0`. The machine stays in Complement for all subsequent non-reset edges, because the first `1` permanently establishes that the remaining bits belong to the complement region. Only reset returns the machine to Copy.

A short worked example: if the sampled input sequence after reset release is `x = 0, 0, 1, 0, 1`, the expected sampled outputs are `z = 0, 0, 1, 1, 0`. The first two zeros keep Copy and output 0. The first 1 moves to Complement and outputs 1 immediately. The next 0 is inverted to 1, and the final 1 is inverted to 0.

For the final Python checker, the useful point is to model the reference with a single two-valued state initialized to Copy. On each sampled positive edge, if `areset` is asserted, force the reference state to Copy and require `z=0`; otherwise update the reference state from the sampled `x` using the transitions above, then compare the sampled `z` to the Moore output of the updated state. Do not assume a particular state encoding or state count, allow `x` to change arbitrarily while `areset=1`, and avoid over-constraining the exact cycle of reset release. The essential invariant is that input sampling and Moore output observation are aligned on the same positive edge.

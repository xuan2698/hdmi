We need to implement a gshare branch predictor with:
- 7-bit PC, 7-bit GHR, XOR → 7-bit index into 128-entry PHT of 2-bit saturating counters.
- Async active-high reset clears GHR and PHT.
- Prediction: combinational read of PHT[index] and GHR; predict_taken = PHT[index][1] (MSB); predict_history = GHR.
- At posedge: if predict_valid and not (train_valid and train_mispredicted), GHR shifts in predicted direction (predict_taken).
- Training: at posedge, PHT[train_pc ^ train_history] saturating-updates toward train_taken.
- If train_valid and train_mispredicted: GHR ← (train_history << 1 | train_taken) & 0x7F, takes precedence over prediction GHR update.

Let me write the reference function.

```python
def reference(vectors):
    # State
    pht = [0] * 128  # 2-bit counters, init 0
    ghr = 0
    out = []
    for v in vectors:
        areset = v['areset']
        if areset:
            pht = [0] * 128
            ghr = 0
            out.append({'predict_taken': 0, 'predict_history': 0})
            continue
        # combinational outputs
        pv = v['predict_valid']
        if pv:
            idx = (v['predict_pc'] ^ ghr) & 0x7F
            pt = (pht[idx] >> 1) & 1
            ph = ghr
        else:
            pt = 0
            ph = 0
        out.append({'predict_taken': pt, 'predict_history': ph})
        # posedge updates
        tv = v['train_valid']
        tm = v['train_mispredicted']
        # PHT update
        if tv:
            tidx = (v['train_pc'] ^ v['train_history']) & 0x7F
            c = pht[tidx]
            if v['train_taken']:
                if c < 3:
                    c += 1
            else:
                if c > 0:
                    c -= 1
            pht[tidx] = c
        # GHR update
        if tv and tm:
            ghr = ((v['train_history'] << 1) | v['train_taken']) & 0x7F
        elif pv:
            ghr = ((ghr << 1) | pt) & 0x7F
    return out
```

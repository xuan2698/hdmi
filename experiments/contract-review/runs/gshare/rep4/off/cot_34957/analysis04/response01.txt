The public interface is small but the boundary behavior is where a checker can go wrong. All control and data inputs are one bit except the two 7-bit PC/history fields and the 7-bit `train_history`; outputs are one bit for direction and 7 bits for the history snapshot. The 7-bit widths mean legal values run from `0` through `127` (`7'b0000000` to `7'b1111111`). There is no wider address space and no separate valid qualifier on the outputs: `predict_taken` and `predict_history` are meaningful only when the sampled `predict_valid` is high, and the checker should not require them to hold any particular value on cycles where no prediction is requested. Similarly, `train_taken`, `train_mispredicted`, `train_history`, and `train_pc` are only meaningful when `train_valid` is high; do not let stale values on those ports perturb the model.

The hash is `predict_pc ^ predict_history` for prediction and `train_pc ^ train_history` for training, each truncated to 7 bits, indexing 128 two-bit saturating counters. Counter values are therefore in `{0,1,2,3}`; the prediction direction is the counter's high bit, so counters 0 and 1 predict not-taken and 2 and 3 predict taken. Training saturates: taken increments toward 3 without wrapping, not-taken decrements toward 0 without wrapping. A prediction and a training that hit the same entry in the same cycle must be ordered so the prediction reads the pre-edge counter and the training write lands at the next edge.

The GHR is 7 bits and is updated at the next positive edge. On a prediction, shift in the predicted direction. On training, the PHT update always occurs; if `train_mispredicted` is high, the GHR is recovered to `train_history` shifted with `train_taken` inserted. When a mispredicted training and a prediction for a different, younger instruction coincide, training wins the GHR update and the prediction's GHR shift is suppressed. The prediction's PHT read still uses the old counter.

Reset is asynchronous active-high and has priority over everything: prediction reads, PHT writes, GHR shifts, and misprediction recovery. A mid-cycle `areset` assertion after a sample must clear GHR and all PHT entries immediately, so the next sampled edge already sees the cleared state. Before any reset, GHR and PHT are undefined; comparison should begin only after reset establishes all-zero state.

Worked boundary check: with `predict_pc = 7'b0000000` and `predict_history = 7'b0000000`, the index is 0. If entry 0 holds 2, `predict_taken` is 1 and `predict_history` is 0. If `train_valid` is high the same cycle with `train_pc = 0`, `train_history = 0`, `train_taken = 0`, the prediction still reports taken from the old counter, while the next edge decrements entry 0 to 1. The checker should sample outputs after the edge settles and model writes as edge-triggered, except for asynchronous reset, which must be applied at assertion time.

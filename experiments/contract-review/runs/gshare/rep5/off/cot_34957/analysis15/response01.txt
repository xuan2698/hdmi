The predictor's state is the 7-bit global history register (GHR) and the 128-entry PHT of 2-bit saturating counters. All state changes are edge-committed at the positive clock edge, except that asynchronous active-high `areset` overrides everything and forces GHR=0 and all PHT entries to `2'b00` immediately (and at the sampled edge). Outputs `predict_taken` and `predict_history` are combinational functions of the current (pre-edge) state and the current inputs; they do not reflect same-cycle training writes.

Prediction path: when `predict_valid=1`, form the index as `predict_pc[6:0] XOR GHR[6:0]` (7-bit). `predict_taken` is the MSB of the addressed 2-bit counter (i.e., counter ≥ 2 means taken). `predict_history` is the current GHR value used for the hash — the pre-edge GHR, not a shifted version. If `predict_valid=0`, the outputs are don't-care for the checker (but a reasonable implementation drives 0/current GHR); the checker should only compare outputs on rows where `predict_valid=1` (or where `areset=1`, per the reset rule).

Training path: when `train_valid=1`, form the training index as `train_pc[6:0] XOR train_history[6:0]`. The addressed counter is updated at the edge: increment (saturating at `2'b11`) if `train_taken=1`, decrement (saturating at `2'b00`) if `train_taken=0`. This write is edge-committed, so a same-cycle prediction to the same index observes the old counter value. If `train_valid=0`, no PHT write occurs.

GHR update at the edge, with priority: (1) if `areset`, GHR←0; (2) else if `train_valid && train_mispredicted`, GHR←`{train_history[5:0], train_taken}` (recovery: the history immediately after the mispredicting branch, i.e., shift `train_taken` into the low bit of `train_history`); (3) else if `predict_valid`, GHR←`{GHR[5:0], predict_taken}` (shift in the predicted direction); (4) else hold. Note that a non-mispredicted training request does not modify the GHR — only mispredicted training recovers it. Training takes precedence over prediction for the GHR when both are valid and the training is a misprediction; a valid prediction in the same cycle is discarded.

Worked example (non-reset): GHR=`7'b0000000`, PHT[0]=`2'b01`, and a row has `predict_valid=1, predict_pc=0` (index 0), `train_valid=1, train_pc=0, train_history=0, train_taken=1, train_mispredicted=0`. Outputs: `predict_taken=0` (counter `01`), `predict_history=0`. At the edge, PHT[0]→`2'b10`; GHR shifts in the predicted bit → `7'b0000000`. Next cycle a prediction to index 0 sees `2'b10` → taken. This illustrates the pre-edge read and the edge-committed write.

Checker guidance: sample outputs after the posedge settles; compare `predict_taken`/`predict_history` only when `predict_valid=1` (or `areset=1`, expecting 0/0). Maintain a shadow GHR and PHT, applying reset override first, then the priority rules above. Remember that a same-cycle prediction must use the pre-edge counter even if training targets the same index, and that only mispredicted training recovers the GHR.

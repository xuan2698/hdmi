The public interface is small but the widths and boundary values matter for the final checker. All data ports are 7 bits wide: `predict_pc`, `train_history`, `train_pc`, and the output `predict_history`. The control and direction ports are 1 bit: `areset`, `predict_valid`, `train_valid`, `train_taken`, `train_mispredicted`, `predict_taken`. The clock is `clk`. Because the PC and history are 7 bits, their legal range is 0 through 127 inclusive; the XOR of two 7-bit values is also 7 bits, so the PHT index is always in 0..127 and directly addresses the 128-entry table. No truncation or sign extension is needed anywhere. The global history register is likewise 7 bits, so after any shift it remains in 0..127; the recovery expression `{train_history[5:0], train_taken}` is exactly 7 bits.

The 2-bit saturating counters have states 0,1,2,3. The prediction output `predict_taken` is the counter's most significant bit, so states 0 and 1 predict not-taken and states 2 and 3 predict taken. Training increments toward 3 on `train_taken=1` and decrements toward 0 on `train_taken=0`; the boundary behavior is that state 3 stays 3 on a taken update and state 0 stays 0 on a not-taken update. The checker should verify these saturation edges explicitly, since they are the most likely place for an off-by-one.

The prediction read is combinational with respect to the current PHT contents and the current `ghr`. For `predict_valid=1`, the index is `predict_pc ^ ghr`, `predict_taken` is the MSB of that entry, and `predict_history` equals the current `ghr` before any edge update. The PHT read must not observe a same-cycle training write; training commits only at the posedge, so a coincident prediction returns the pre-edge counter value. This is a key checker point: model the PHT as a registered array whose write takes effect after the sampled edge, while the read path uses the stored value.

At the posedge, priority is reset first, then mispredicted training, then prediction, then hold. Reset is asynchronous active-high, so it must override state immediately, including mid-cycle, and must suppress PHT writes and history changes. A mispredicted training performs the PHT update and sets `ghr` to `{train_history[5:0], train_taken}`. A non-mispredicted training performs the PHT update but leaves `ghr` unchanged. A prediction with no higher-priority event shifts the predicted direction into `ghr`. When mispredicted training and a younger prediction coincide, training wins for `ghr`; the PHT write still commits, and the prediction's read used the old PHT value.

Worked boundary example: suppose `ghr=127`, `predict_pc=127`, so index `127^127=0`. If PHT[0]=3, then `predict_taken=1` and `predict_history=127`. At the posedge with only `predict_valid=1`, `ghr` becomes `{127[5:0],1}=255` truncated to 7 bits, i.e. `(127<<1 | 1) & 127 = 127`. This confirms the shift wraps within 7 bits and that the checker must mask to 7 bits rather than allowing an 8-bit intermediate to leak into state.

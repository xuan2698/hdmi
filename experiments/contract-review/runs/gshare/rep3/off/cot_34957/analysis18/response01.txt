One likely implementation mistake is to treat the prediction and training interfaces as if they share a single "current" branch-history value, rather than respecting that the prediction output must reflect the GHR state *before* any same-cycle training recovery. A common bug: when `train_valid && train_mispredicted` coincides with `predict_valid`, the RTL computes `predict_history` from a combinational GHR that has already been muxed toward the recovered `train_history`. The spec requires the prediction to report the pre-edge GHR (the value used to form the index), while training's recovery only takes effect at the next positive edge. If the checker only verifies `predict_taken`, this bug slips through; it must also compare `predict_history` against the GHR value that actually indexed the PHT that cycle.

A second, related mistake is ordering the PHT read after the training write in the same cycle. The spec explicitly says the prediction sees the pre-training PHT state, with the write landing at the next edge. An implementation that lets training update the counter combinationally (or that reads a "next" value) will return the post-update MSB. The checker should prime a counter to a boundary state (e.g., 2 or 1) and issue a same-cycle predict+train that would flip the MSB, then confirm the prediction used the old MSB.

A third mistake concerns reset: treating `areset` as synchronous or letting a same-cycle mispredicted training override the asynchronous reset of the GHR. The checker should assert reset concurrently with a distinctive `train_history` recovery and confirm the post-reset `predict_history` is the reset value, not the recovered one.

Finally, hash errors: indexing on `predict_pc` alone, or XORing the wrong bit ranges, will pass naive tests but fail aliasing probes where distinct `(pc, history)` pairs collide to the same index. The checker should include at least one pair with equal `pc` but different history mapping to different indices, and one pair with different `pc`/history mapping to the same index, verifying both the predicted direction and the reported history.

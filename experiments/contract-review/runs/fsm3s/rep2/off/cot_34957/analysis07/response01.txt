The key timing point for the checker is that the Moore output is a function of the **post-edge state**, not the pre-edge state. The table's output column is attached to the state itself, so after a sampled edge the checker must first resolve the next state (with synchronous reset taking priority), then read `out` from that resolved state. This is why the C→D transition is the only place where a 0→1 output change can occur on an edge, and why leaving D always produces a 1→0 output change on the following edge regardless of input.

Reset is synchronous and active high, so it is evaluated at the same edge as the transition table and overrides it. If `reset=1` is sampled while in C with `in=1`, the machine goes to A and the output is 0; the checker must not report the D output of 1. Likewise, a reset edge sampled while in D produces state A and output 0, so the D output does not survive a reset edge. The checker should apply reset before computing the next state and before reading the Moore output.

The public specification gives no power-on state. The checker should not assume A before the first reset-sampled edge. A robust sequence is to sample one edge with `reset=1` to force A, then begin comparing state and output from the following settled edge. Expected-state tracking before that first reset edge would depend on an initialization convention not present in the table.

Mid-input changes occur after sampling and before the other edge. They do not cause a transition and do not change the output just sampled. They become the starting input for the next row unless that row drives a new value. The checker should keep the sampled input for each edge distinct from any later mid-row input value.

Worked example: current state C, output 0, row drives `in=1`, `reset=0`. The sampled edge moves C to D and the settled output becomes 1. A mid-row change of `in` to 0 is carried to the next row and does not alter the C→D transition or the output 1. On the next sampled edge with `in=0`, `reset=0`, D moves to C and the output returns to 0. This compact sequence exercises the only output-1 state, the one-edge transient, and the post-edge Moore-output rule, and it is a useful distinguishing test for the final checker.

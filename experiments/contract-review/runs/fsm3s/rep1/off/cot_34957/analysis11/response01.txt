The key checker point is edge-sampled Moore semantics with reset priority. At each rising edge, capture `in` and `reset` as driven before the edge. If `reset` is 1, the next reference state is A; otherwise use the transition table from the current reference state and the captured `in`. The expected output after the edge is the Moore output of that next state, not the pre-edge state. Mid-cycle input changes after sampling are carried to the next edge and must not retroactively change the just-entered state's output.

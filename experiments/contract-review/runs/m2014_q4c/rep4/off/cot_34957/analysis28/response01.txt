The ports are all one bit wide: `d`, `r`, and `q`. Boundary values are therefore only 0 and 1; there is no multi-bit truncation or masking concern. The key semantic boundary is the sampled positive edge: pre-edge `r=1` forces next `q=0`, while pre-edge `r=0` makes next `q` equal pre-edge `d`. The observed `q` must be checked only after the edge settles.

A useful checker point: treat `q` as the only model state and enforce strict ordering—read pre-edge inputs, compute expected next `q`, compare settled output, commit state, then apply any mid-row input changes for the next row. Example: state `q=1`, pre-edge `d=0,r=0` gives expected `q=0`; a later mid-row `r=1` belongs to the next row and must not alter this comparison. Power-up `q` is unspecified, so the harness must supply or establish it.

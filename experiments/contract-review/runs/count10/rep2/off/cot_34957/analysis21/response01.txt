The public specification defines a synchronous, active-high reset decade counter. The key behavioral facts are:

1. **Reset priority.** When the sampled `reset` input is high at a rising edge, the next sampled `q` must be 0, regardless of the current `q`. Because reset is synchronous, it affects the transition taken at that edge, not the value already sampled before it.

2. **Normal decade counting.** When sampled `reset` is low and the current `q` is a valid decade state (0 through 9), the next `q` is `q + 1` for 0–8, and 0 for 9. The period is therefore 10.

3. **Undefined out-of-range behavior.** The specification does not define a normal successor for `q` values 10–15 when reset is low. The checker should not assume those states wrap to 0 or follow any other invented rule. Only a high sampled reset forces the next state to 0 from an out-of-range value.

4. **No specified power-up value.** The specification does not require the counter to start at 0. The first sampled row should be treated as an observed state, and transitions should be checked from that observed `q`. If the first sampled `q` is 0, that is allowed but not mandatory.

5. **Timing and mid-cycle changes.** Each row’s inputs are driven before the sampled rising edge. Optional mid-cycle input changes occur after sampling and before the next edge, and they apply only to the next row. A reset asserted after a sampled edge must not retroactively change the expected transition for the edge just sampled.

A short worked example: suppose at one sampled edge `q = 9` and `reset = 0`. The expected next `q` is 0. After sampling, `reset` goes high before the next rising edge. At the next sampled edge, current `q = 0` and sampled `reset = 1`, so the expected next `q` is 0. The earlier 9→0 transition remains valid; the later reset applies only to the following transition.

For the final Python checker, the useful decision order is: read observed `q` and sampled `reset`; if `reset` is high, expect next `q = 0`; otherwise, if observed `q` is in 0–9, expect the decade successor with 9→0; otherwise, do not impose a normal transition. Carry post-sampling input changes only to the next row. This avoids the common errors of letting reset priority leak backward, requiring an unspecified initial 0, or inventing behavior for out-of-range states.

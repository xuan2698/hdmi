The ports are `reset` (1 bit, active-high synchronous) and `q` (4 bits, though only values 0–9 are legal). The checker must reject any sampled `q` in 10–15 outright, regardless of reset, since that proves the counter left the decade set. Reset is sampled at the same posedge as `q`; a reset asserted before edge N yields `q=0` at edge N. The expected transition is `0` if the latched reset is 1, else `(prev+1) mod 10`. Post-edge reset changes belong to the next row. Initialization is unspecified, so the first sample should not be assumed 0; begin judging from the second row or require an initial reset assertion. Example: prev=9, reset=0, observed q=0 passes as a wrap; a later reset change must not retroactively alter that row.

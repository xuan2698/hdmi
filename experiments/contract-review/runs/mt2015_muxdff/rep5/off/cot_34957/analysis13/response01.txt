The public spec defines a three-bit register whose next state is either the load value `r` when `L = 1`, or the linear map `{q[1]^q[2], q[0], q[2]}` when `L = 0`. The hierarchical implementation splits this into three one-bit submodules, each containing a flipflop and a 2-to-1 mux. Because every submodule port is exactly one bit wide, any misrouting among the three instances — swapping which old bit feeds which mux, or which XOR term lands in which output position — is width-legal and structurally invisible. The checker must therefore be behavioral, not structural.

The timing protocol is: values are driven before the sampled posedge; the sample occurs after the posedge has settled; optional mid-cycle input changes occur after sampling but before the next edge and are carried into the next row's snapshot. This means the checker must latch the three old `q` bits at the sampled edge, compute the expected next state from those latched bits, and compare against the settled `Q` for that same row. It must not re-read `q` after the edge, because `q` has already advanced. It must also not fold a mid-cycle change into the current row; that change belongs to the following row.

A useful point for the final Python checker: the next-state map is not symmetric, so test vectors must distinguish bit positions. All-zero and all-one states are fixed points under `L = 0` (`000 -> 000`, `111 -> 111`), and under `L = 1` they only exercise the load path. Neither exposes a permutation error. The checker needs at least one mixed state with `L = 0` and a nontrivial `r`, plus a load test with a mixed `r` to confirm all three bits load simultaneously rather than bit-serially.

Worked example: drive `q = 3'b110`, `L = 0`. Correct next state is `{1^1, 0, 1} = 3'b001`. If the instance computing bit 0 is fed `q[1]` instead of `q[2]`, the low bit becomes `1` and settled `Q` is `3'b011` — a one-bit, width-legal error visible only on a mixed state.

The checker should snapshot old `q` at the edge, evaluate the three expressions independently, compare the full settled vector, respect the harness-declared initial `q` (no assumed reset), and attribute mid-cycle changes to the next row.

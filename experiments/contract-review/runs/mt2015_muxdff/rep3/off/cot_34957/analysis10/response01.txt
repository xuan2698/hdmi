The public spec fixes the interface at one bit per data port: `L`, `r_in`, `q_in`, and `Q` are each 1 bit wide, while `clk` is the single clock. The original `full_module` used a 3-bit `r` and 3-bit `q`, but the hierarchical `top_module` described here is the per-instance submodule: one flipflop plus one 2-to-1 mux, instantiated three times inside the enclosing design. So the checker must not assume a 3-bit bus at the submodule boundary; it must treat each instance as a 1-bit slice and reconstruct the 3-bit LFSR word from the three instances' `Q` outputs and the three `r_in`/`q_in` connections.

Boundary values are therefore binary only: `L ∈ {0,1}`, `r_in ∈ {0,1}`, `q_in ∈ {0,1}`, `Q ∈ {0,1}` once known. The only non-binary states are `x` and `z`, which can appear on `Q` before any load because there is no reset. The mux behavior is: when `L=1`, `Q` follows `r_in`; when `L=0`, `Q` follows the flipflop's stored next value, which for the enclosing LFSR is the XOR/shift function. At the submodule level the checker should verify that the mux selects `r_in` under `L=1` and selects the flipflop feedback under `L=0`, and that the flipflop captures on `posedge clk`.

The important boundary condition for the final Python checker is the unknown pre-load state. A row with `L=0` and unknown pre-edge `q` cannot yield a predictable `Q`; the checker should skip such rows or require an explicit load first. A row with `L=1` is always predictable regardless of pre-edge `q`, because the load overrides the feedback path. Mid-row input changes after sampling are carried to the next row and must not affect the current row's reference.

Worked example: first sampled posedge has `L=1`, `r_in=1`; pre-edge `Q=x`. After the edge `Q=1`. Next row `L=0`, pre-edge `q=1`; reference next `Q` is the feedback bit, which the checker computes from the reconstructed 3-bit word, not from the single bit alone. If the first row had `L=0`, the row is skipped.

Useful point for the checker: gate functional comparison on known pre-edge `q`, allow the first sampled posedge to be unknown, and keep structural checks (three instances, mux/flipflop connectivity, XOR destination) independent of power-up state.

The public spec fixes the submodule boundary: each instance contains one flipflop and one 2-1 mux, with `L` selecting `r_in` versus the feedback word. The three instances are wired so bit 2's feedback is `{q[1]^q[2]}` (XOR of two external bits), bit 1's feedback is `q[0]`, and bit 0's feedback is `q[2]`. A checker that only validates each submodule standalone cannot catch a swap of these cross-connections, because every instance would still look like a legal mux-plus-flop. The structural pass must therefore assert the exact source expression feeding each instance's feedback port, independent of whether the sampled data happens to match.

Functionally, the useful discriminator is dependency-aware comparison. With `L=1`, all three slices load `r` and are fully checkable on the first edge, so `r=3'b111` and `r=3'b000` cleanly separate stuck-at from swap faults. With `L=0`, unknown prior bits poison only dependent slices: bit 2 needs `q[1]` and `q[2]`, bit 1 needs `q[0]`, bit 0 needs `q[2]`. Compare a slice only when its feeding pre-edge bits are known; skip otherwise. Mid-window changes belong to the next row and must not be attributed to the just-sampled edge.

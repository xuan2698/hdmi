# Stimulus v2 开发集结果

完成 10 题 × 10 个种子 × 5 种配置，共 500 个运行检查点。两组 H 沿用 100 个原组项和 95 个难触发项，后者包括 10 个未定项。最终测试集仅保留划分中的 15 个题号。

在难触发 H 上，共享初稿从 4,000 周期放长到 20,000 周期，暴露率增加 **6.19 个百分点**。已在 20,000 周期处对齐预算时，O 比 A0-long 高 **1.75 个百分点**，O 比 B 高 **0.18 个百分点**，两项配对区间都跨零。O+F 在两组 H 的点估计最高，四组按题配对比较均未达到 0.05。Ring Token 的迭代增益最明显，秒表的 A0-long 在两组中都高于三种迭代配置。结论限于十道开发题及冻结参数。

## 诊断修复

v1 全部 2,378 条诊断使用各自原激励前缀重放。原来稳定分类 774 条（32.55%），修复后稳定分类 2,194 条（92.26%），其中未到达 196、未感染 1,084、未传播 914。原有 774 个标签均保持一致，原先未定的 1,604 条有 1,420 条得到新标签。仍未定的 184 条全是阻塞/非阻塞调度差异缺少可支持的局部观测。

| v1 未定原因 | 条目数 | 在 v1 未定中的比例 | 例子 |
| --- | ---: | ---: | --- |
| 阻塞与非阻塞调度变化，旧工具只比较右值 | 558 | 34.79% | IIR G01 同一行上把首个 `butterworth_a_0 = 0` 改成 `<=` |
| 赋值插入或删除，旧工具找不到一对表达式 | 529 | 32.98% | IIR G09 多插入一条 `y_2_0 <= 0` |
| 下标、嵌套或复合条件超出旧正则 | 401 | 25.00% | RAM G19 扩展 `if (be_b_reg[2])` 条件 |
| 触发边沿缺少旧表达式探针 | 82 | 5.11% | RAM G15 把正沿改为负沿 |
| 枚举探针的赋值被拒绝 | 34 | 2.12% | Hill Cipher G16 包装 `next_state` 时 Icarus 要求显式枚举转换 |

修复用 pyslang 语法树定位源语句，探针记录赋值执行、分支决策或进程事件时间。值比较以目标位宽为准，对参考确定的位逐位比较。对缺少确切证据的调度变化保留未定。独立复核用相同语句位置的原始逐事件日志，另用 Python 重算已知位差异、执行和事件时间分布。随机抽 30 条，28 条可判定，28 条标签一致（可判定样本一致率 100%，占全样本 93.33%），另 2 条两种方法都未定。这是同一仿真器上的交叉核对。[诊断明细与实例](../audits/diagnostic/summary.json) · [30 条交叉核对](../audits/diagnostic/sample.json)

## 形式化历史排查

v1 的 49 个超时中，3 个全尺寸 RAM 项在 Yosys 综合阶段用完整个时限，其余 46 个已进入 Boolector 断言检查。9 个报错中，5 个是 `xprop` 遇到多驱动，3 个是 Yosys 拒绝多边沿敏感事件，1 个是 `always_comb` 的变异分支被推断为锁存器。新实现只综合一次，用 2、6、16、36 周期四阶段搜索。共享逻辑合并和无关扇入清理在 Yosys 内完成。RAM 使用八地址做受限搜索，锁存器和多驱动的兼容转换只提供候选反例。所有反例都用原 RTL、正式参数和评分口径复放。[历史超时阶段](../audits/v1_formal_timeout_phases.json) · [69 个同一 G 项的前后对照](../audits/formal.json) · [新求解记录](../formal/)

复放证据包含首次输出差异的前一拍和当拍的双边沿内部采样。例如秒表 G04 在第 6 个周期下降沿出现第一处输出差异，该拍记录了 `counter=0` 和 `one_sec_pulse=1`。Ring Token G12 的反例在第 2 个周期下降沿暴露，保存两边的 `current_state=2'b01` 和 `next_state=2'b01`。部分 DUT 的变异位置附近没有可读取的内部寄存器，归档会保留能采样的公开输出和时钟相位。[秒表反例](../formal/cvdp_copilot_digital_stopwatch_0017/G04.json) · [Ring Token 反例](../formal/cvdp_copilot_ring_token_0004/G12.json)

## 核验与复放

在冻结提交 `0a424d75cda2630745f724f13b8a9c139fab2395` 之后开始模型调用。归档核验逐运行检查预算与共用前缀，从源代码和种子随机重建 12 段向量，对照记录的 SHA-256。原 H 与难触发 H 在 500 个生成检查点齐备后才由评测脚本打开。数据装载验证发布集的固定 SHA-256 并且只读取十个开发题的记录。求解脚本只使用 G 清单。[冻结协议](../README.md) · [归档核验](verification.json) · [H 评测入口与完成记录](../evaluation/verification.json)

可从已归档的模型源文件和种子重建激励，无需调用模型。实际工具为 Icarus 12.0、Yosys 0.52、Boolector 3.2.4 和 pyslang 12.2.0。Yosys 和求解器可通过仓库已有脚本安装。环境 PATH 还需包含 `bwrap`、`iverilog` 和 `vvp`，Python 需要 `pyarrow`、`pyslang`、`numpy`、`scipy`。[工具安装](../../equiv-audit/setup.sh) · [双态及 X 屏蔽求解验证](../audits/solver_smoke.json)

```bash
curl -fLo dataset.parquet https://huggingface.co/datasets/hez2024/CVDP-ECov-eval/resolve/26a8b0012436b460c539ebe5f893fba6e1d601a4/data/eval-00000-of-00001.parquet
python3 stimulus-v2/diagnostic_audit.py dataset.parquet --summary-only
python3 stimulus-v2/verify.py dataset.parquet
python3 stimulus-v2/score.py dataset.parquet --replay
python3 stimulus-v2/report.py
```
